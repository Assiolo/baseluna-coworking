Base Luna Coworking — avvio locale
1. Installa Node.js (https://nodejs.org) se non ce l'hai
2. Apri il terminale nella cartella baseluna-coworking
3. npm install
4. Imposta DATABASE_URL (Postgres / Neon, meglio l'host pooled). Senza questa variabile il server non parte.
5. node server.js
6. Apri http://localhost:5173 nel browser

Il primo account registrato diventa admin, se non ce n'è già uno.
Account, sessioni, prenotazioni, pagamenti, prezzi dei pacchetti e foto profilo stanno su Postgres, non più su file locali.
